# Video placeholders

Add WEC-Sim visualization videos here after running `output.saveViz(...)` or after exporting animations from MATLAB.

Recommended names:

- `baseline_decay_wecsim.mp4`
- `hollow_owc_regular_ss3_wecsim.mp4`
- `hollow_owc_irregular_ss3_wecsim.mp4`

Keep large videos out of Git history if the files exceed GitHub's practical size limits. Use Git LFS if needed.
